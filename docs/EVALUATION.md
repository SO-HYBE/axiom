# AXIOM three-arm evaluation

The evaluation compares a plain model, existing RAG, and RAG plus AXIOM over the same frozen 36-question benchmark. The recorded run is `3c3cc0f1e4b949a8a33296e94417f13c` (108 scheduled jobs; 106 completed; two execution failures). A fresh model run was not made because provider credentials were unavailable. RAG-only and AXIOM use the same saved draft, so their comparison measures checking/withholding rather than a separate drafting call.

Full generated output: [REPORT.md](../runs/axiom/evaluation/REPORT.md) and [results.json](../runs/axiom/evaluation/results.json). They include commit, run timestamp, dataset size, arm counts, answer/abstention rates, retained claims, mechanical citation resolution, monitor verdicts, paired answer/abstention outcomes, provenance, and limitations. Question-level answer coverage, abstention rate and expected-action agreement include descriptive 95% percentile intervals from 2,000 seeded question resamples. The agreement labels are agent-drafted and unreviewed; the intervals do not turn them into ground truth.

Semantic claim evidence support, citation-to-source correctness, unsupported quantitative claims, unsupported generalizations, applicability correctness, answer correctness and faithfulness have no independent scored labels. Each is null, not zero. A citation ID found in retrieved evidence is only a structural resolution check, not evidence that the quoted source supports the prose claim. The shuffled review packet and private mapping live with the recorded benchmark run; the packet contains no grades. Unblind only after completed scoring.

The recorded results do not establish that AXIOM improves answer correctness. On the paired subset, the observed answer/abstention differences and claim retention are descriptive. The sample is one small question set over one corpus; no significance or population claim is supported. The output must be allowed to show no benefit, a coverage cost, or failure when future reviewed scores exist.
